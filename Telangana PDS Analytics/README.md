This project focuses on analyzing the Telangana Public Distribution System (PDS) data to understand shop behavior and transaction patterns. The objective was to preprocess and integrate the provided datasets, perform exploratory data analysis, engineer meaningful features, and apply clustering techniques to segment shops based on their operational characteristics.

The project involved data cleaning, feature engineering, feature scaling, and dimensionality reduction using Principal Component Analysis (PCA). K-Means clustering was used to group shops with similar transaction and utilization patterns, while DBSCAN was employed to identify unusual or anomalous shop behavior. Cluster profiling and visualization were carried out to interpret the characteristics of each group and extract meaningful insights.

Finally, an interactive Streamlit dashboard was developed to present the analysis and enable easy exploration of the results through visualizations and filters.
