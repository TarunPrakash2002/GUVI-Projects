This project focuses on sentiment analysis of financial news headlines using deep learning and BERT. The dataset was preprocessed and multiple models, including Simple RNN, LSTM, GRU, and BERT, were trained and evaluated to classify news as Bearish, Bullish, or Neutral. Model performance was compared using Accuracy, Precision, Recall, Macro F1-score, and Confusion Matrix, with BERT achieving the best overall performance. A Streamlit application was also developed to allow users to predict the sentiment of financial news in real time.

Four different models were trained and compared in this project: Simple RNN, LSTM, GRU, and BERT. The Simple RNN gave the lowest performance because it could not capture the context of the text effectively. LSTM improved the results by remembering important information for longer, and GRU performed slightly better than LSTM with a simpler architecture. BERT achieved the best performance with the highest Accuracy (86.77%) and Macro F1-score (83.03%) because it understands the context of the entire sentence more effectively than the other models.
